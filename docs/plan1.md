# Demo 方案规划

## 📋 目标

创建一个在线 demo，展示 review-html 的核心功能，吸引用户使用。

## 🎯 Demo 内容

### 核心功能展示

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 标签系统 | 掌握/理解/了解 三级标注 | ⭐⭐⭐⭐⭐ |
| 速记卡片 | 公式/地址/数据速查 | ⭐⭐⭐⭐⭐ |
| 表格转置 | 移动端自动优化 | ⭐⭐⭐⭐ |
| 导航方案 | 快速导航 + 全屏导航 | ⭐⭐⭐⭐ |
| 折叠功能 | 手风琴折叠 + 折叠所有 | ⭐⭐⭐ |
| 代码模板 | 编程类科目常用代码 | ⭐⭐⭐ |
| 数学公式 | MathJax/LaTeX 支持 | ⭐⭐⭐ |

### Demo 科目选择

| 选项 | 科目 | 优点 | 缺点 |
|------|------|------|------|
| A | 单片机 | 已有完整内容 | 太专业 |
| B | 概率论 | 有公式展示 | 已有项目 |
| C | 英语 | 通用性强 | 内容多 |
| D | 通用模板 | 简洁通用 | 不够具体 |

**推荐**：使用单片机内容，因为：
1. 已有完整内容（11个模块）
2. 涵盖所有功能（标签/代码/速记卡片）
3. 可展示表格转置效果

## 📐 Demo 设计规范

### 内容精简

| 原始 | Demo | 说明 |
|------|------|------|
| 11 个模块 | 3-4 个模块 | 精简内容 |
| 完整知识点 | 代表性知识点 | 展示结构 |
| 所有代码模板 | 1-2 个模板 | 展示格式 |

### 功能展示

| 功能 | 展示方式 |
|------|----------|
| 标签系统 | 每个知识点都有标签 |
| 速记卡片 | 独立模块展示 |
| 表格转置 | 对比横向/纵向表格 |
| 导航方案 | 快速导航标签 |
| 折叠功能 | 默认展开第一个 |

### 样式要求

- 使用蓝白主题（默认）
- 响应式设计
- 移动端友好

## 🚀 部署方案

### GitHub Pages 配置

1. 进入仓库 Settings → Pages
2. Source 选择 `Deploy from a branch`
3. Branch 选择 `main`，目录选择 `/docs`
4. 保存后自动部署
